# Code of Conduct

We are committed to a respectful, harassment-free project for everyone. Be
constructive, assume good intent, respect privacy, and disagree with ideas rather
than people. Harassment, threats, discrimination, sexualized attention, and
publishing private information are not acceptable.

Project maintainers may edit or remove contributions and restrict participation
when behavior harms the community. Report conduct concerns privately through the
repository owner's GitHub profile contact. Reports will be handled as
confidentially as practical.
